# Lexical Analyzer in C

## Overview
This project implements a Lexical Analyzer in C as part of Embedded Systems training at Emertxe Technologies.

A lexical analyzer processes source code and identifies tokens such as keywords, identifiers, operators, and constants according to the rules implemented in the program.

## Features
- Reads and processes source code.
- Identifies tokens using lexical analysis concepts.
- Uses separate source and header files for modular implementation.

## Technologies Used
- C Programming
- Header Files
- String Processing
- VS Code

## How to Compile and Run

Make sure GCC is installed on your system.

Compile the program:

```bash
gcc main.c lexer.c -o lexer
```

Run the executable:

```bash
./lexer
```

On Windows, run:

```bash
lexer.exe
```
